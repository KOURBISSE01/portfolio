🏆 Hackathon GenAIComputer VisionAgents

🥇 NutriVision — Assistant IA Nutrition

Projet lauréat « Build with Gemma Hackathon »

Assistant nutritionnel alimenté par l'IA qui analyse des photos de plats, détecte les plats marocains avec YOLOv8 (70 plats), fournit une analyse nutritionnelle via Gemma 4B et génère des recommandations personnalisées et des plans de repas selon les conditions de santé.

  • Architecture multi-agents (vision, RAG, nutrition, superviseur)
  • Détection de plats MFOOD YOLOv8 + analyse Gemma LLM
  • RAG avec ChromaDB · Frontend React + Vite · Backend Flask · Firebase
